# Site Volunteer Guide

## Start

1. Open `https://app.example.com/login`.
2. Choose your site role.
3. Run `/test` before joining the production flow.

## Greeting Mode

- Keep camera framed before the operator takes the feed.
- Use the media control bar to mute or unmute.
- Watch the network quality line under the video grid.
- If video freezes, press `Reconnect`.

## Program Mode

- Remote site microphones are muted by default.
- Use `/player/program` for the program feed.
- If playback stalls, press `Reload stream`.
- Do not switch modes; the operator controls the production mode.

## Quick Fixes

- No camera: check browser permissions, then use `/test`.
- No audio: confirm the right speaker is selected on the OS.
- Playback delay: LL-HLS is expected to be a few seconds behind live.
- Browser asks for permissions again: allow camera and microphone for `app.example.com`.
